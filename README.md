# 🐷 Pigllet

Pigllet is a mobile app for personal finance tracking built with React Native and Expo.  
It helps users manage income, expenses, budgets, and subscriptions in a simple and clear way.

_Pigllet adalah aplikasi mobile untuk mencatat keuangan pribadi yang dibuat dengan React Native dan Expo.  
Aplikasi ini membantu pengguna mengelola pemasukan, pengeluaran, anggaran, dan langganan dengan cara yang mudah dan jelas._

---

## ✨ Features

- Track income and expenses
- Manage budgets
- Unlimited account
- Organized transactions by category
- Simple and intuitive UI
